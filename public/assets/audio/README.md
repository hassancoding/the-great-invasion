# Audio assets — The Great Invasion

Wave 1 ships with **Web Audio synthesis** (no binary files required).
Drop production files here using the paths in `src/phaser/assets/audioManifest.json`.

```
audio/
  music/
    echoes_of_the_riftlands.ogg
    the_failing_well.ogg
    dominion_rising.ogg
    wells_of_fate.ogg
    heart_of_the_rift.ogg
  sfx/
    jump.ogg land.ogg dash.ogg slash.ogg heavy.ogg hit.ogg stomp.ogg
    hurt.ogg crystal.ogg bounce.ogg well_hum.ogg well_charge.ogg
    well_stable.ogg surge.ogg reaver_charge.ogg hulk_slam.ogg
    shield_block.ogg victory.ogg defeat.ogg ui_click.ogg ui_confirm.ogg star.ogg
```

Preferred format: **OGG** (loop-friendly, smaller). MP3 fallback acceptable.
Loop points should be authored seamless for music beds.
